## Hi, I'm Bárbara 👋

**Analytics Engineer / BI Engineer** · Vitória, ES, Brazil · 4+ years in data

I work on the layer between raw data and decisions: lakehouse pipelines, dimensional models and Power BI semantic models that business teams can trust, built and reviewed like software (versioned, documented and governed).

## What I do

- **Lakehouse and pipelines:** analytical datasets in Databricks (Spark SQL, Delta Lake), structured in Silver/Gold layers for BI consumption. ETL/ELT with Python and SQL.
- **Data modeling:** star schema design, Power BI semantic models (DAX, Power Query, RLS), data validation and QA.
- **Governance and DataOps for BI:** led the migration of all Power BI projects to Git: repository structure, branching strategy, branch protection policies, pull request review and Azure DevOps / VS Code workflows. Trained the BI team and wrote the internal documentation.
- **Business partnership:** turning stakeholder questions into KPIs, requirements and dashboards that people actually use (layout design in Figma).
